# LSK H/SEQ 쉬프터 v0.4 — 모듈형 / CNC 6061 / 설계 문서

> 제작: **Sunggwan**

7단+R H패턴(표준·도그레그) + 시퀀셜. **124 × 111 × 199mm** (베이스 124×104, 모드 노브 포함 X 135).
부품 예상가 약 10.5만원 (6061 소재 + 구매품, 직접 CNC 기준).

## 1. 시퀀셜 원리 (부품이 줄어든 이유)
H 캠은 싱크로 고개(약 20N @6.4°)를 넘으면 힘이 7N으로 '툭' 떨어지고 8.8°부터 빨려 들어갑니다.
시퀀셜 모드에서는 잠금 포켓이 꼬리 끝을 물어서 **앞뒤 ±8°에서 정지 + 좌우 고정**.
→ 0~8° 구간은 힘이 항상 중앙 쪽이라 스프링처럼 복귀하고, 6.4°~8°의 힘 낙차가 '딸깍'이 됩니다 (`images/feel_curves.png` 오른쪽).
- 모드 전환: 앞쪽 널링 노브 180° 회전 → 편심(오프셋 3mm)이 잠금 암을 6mm 들어 올림. 양 끝이 사점이라 저절로 고정, 손 힘 거의 없음.
- 펌웨어: 7.0°에서 시프트 신호 (클릭 직후, 스톱 전).

## 3. 손맛
- H: 중립 디텐트 약 7N → 싱크로 고개 약 20N → 빨려 들어감 (−8~−10N) → 14° 금속 스톱. 고개 폭 노브 기준 약 6.5mm. 시뮬레이션 오차 평균 0.7N.
- 시퀀셜: 중앙 디텐트 → 20N 고개 → 클릭 → 8° 스톱, 놓으면 중앙 복귀.
- 좌우: 3-4 기본 (예압 약 5N), 1-2/5-6 약 10N, 7·R 진입 문턱 약 18N.

## 4. 디자인
- 색 구성 제안: **타워·베이스·카세트 = 블랙 아노다이징**, 크래들·허브·캠·게이트·노브 = 생알루미늄 (비드 블라스트), 카트리지·잠금 암 = 오렌지 ABS 포인트.
- 판재 모서리 R2~R8 라운드 + 0.5~0.8mm 모따기, 볼트는 접시머리로 숨김.
- −Y 타워 창으로 캠·롤러가 보이는 '시계 무브먼트' 느낌 (부가티), 게이트 아래 메커니즘 노출 (파가니), 금속 게이트 각인 (페라리), 짧고 단단한 스로우 (포르쉐).

## 5. 검증
- CAD 간섭 검사: **모든 부품 쌍 × 25개 자세** (H 모든 기어·중간 위치·게이트 이동, 시퀀셜 ±7.8°) → 간섭 0
- 잠금 암 올라오는 중간 (25/50/75%) 꼬리와 간섭 0, 포켓 스톱이 ±8°에서 닿도록 양쪽 길이 따로 맞춤 (11.0 / 13.2mm)
- 캠 시뮬레이션: 경로 곡률 반경 8.6mm ≥ 롤러 8mm
- 펌웨어: 판정 로직 단위 테스트 전부 통과 (H 양쪽 배열, 히스테리시스, 시퀀셜 7°, 14비트 랩어라운드), 스케치 문법 검사 통과
- **안 한 것**: 실물 가공·조립, RP2040 보드 컴파일 (Arduino IDE에서 확인 필요)

## 7. 조립 (모듈 순서)
1. **M3**: 허브 + 레버(Ø8, 무두볼트 M4 ×2) + 꼬리(M5×45, 너트 슬롯) → 625 ×2 + M5×40으로 크래들에. +Y 벽에 중공 핀 접착
2. **M4**: 플런저·스프링·S2 컵·M5 무두볼트 → M3 ×4로 크래들 아래에
3. **M5**: 캠을 크래들 −Y면에 M3 ×2 / 카세트 프레임 + 암 + 롤러 + 금형 스프링 + M6 예압 → 베이스에 M3 ×4
4. **M2 + M1**: 타워 F625 압입 → 베이스에 M4 접시머리 ×4 → 크래들 끼우고 −Y M5×45 축, +Y 핀 + 칼라
5. **M6**: 잠금 피벗·암·편심 축·베어링 블록·모드 노브, 마이크로스위치
6. **M9**: 센서 캡 2개 + 케이블 홈 배선 → 베이스 포켓 RP2040 → 바닥 커버
7. **M7 + M8**: 게이트 M3 접시머리 ×4 → 노브
8. 캘리브레이션 (중립 → 1단) → 튜닝

## 9. 리스크
- 캠 6061: 계산상 항복 대비 여유 약 1.3배 → 하드 아노다이징 권장, 눌림 생기면 캠만 교체 (모듈)
- arduino-pico Joystick의 축 범위(0~1023 가정)는 코어 버전에 따라 다를 수 있음 → 첫 연결 때 확인
- MT6701 보드는 판매처마다 모드 핀 설정이 달라 I2C 모드 확인 필요
- 중공 핀 안 배선: 30AWG 실리콘선 4가닥 (약 1.5mm 다발) 기준, 피치 ±14° 비틀림만 받음
- 실물 검증 전 — 캠 + 카세트 + 짐벌만 먼저 조립해서 손맛 확인 추천
