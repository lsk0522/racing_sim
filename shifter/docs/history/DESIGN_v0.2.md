# LSK H/SEQ 쉬프터 v0.2 (소형) — 설계 문서

심레이싱용 개인 쉬프터. 7단+R H패턴(표준/도그레그) ↔ 시퀀셜, 부품 예산 15만원 (예상 약 9.1만원).

## 0. v0.1 → v0.2 변경점 (소형화)
| 항목 | v0.1 | v0.2 |
|---|---|---|
| 전체 크기 (가로×세로×높이) | 220 × 183 × 349mm | **150 × 132 × 252mm** |
| 피벗 → 노브 | 190mm | 140mm (조절 가능) |
| 피벗 → 게이트 | 118mm | 75mm |
| 레버 | SUS Ø12 | SUS Ø10 |
| 베어링 | 608ZZ + 625ZZ | **625ZZ 한 종류** |
| 캠 반경 / 스프링 배치 | 95mm, 암 앞쪽 아래에서 밀어 올림 | 62mm, **암 뒤쪽 위에서 눌러 내림** (예압 나사가 위로 나옴) |
| 모드 전환 | 가로 레버 | **앞쪽 회전 노브 + 크랭크** (양 끝에서 사점 → 저절로 고정) |
| 앞뒤 스로우 (노브 기준) | ±40mm | ±29mm (더 짧고 빠름) |
- 노브에서 느껴지는 힘 곡선은 그대로 유지 (싱크로 고개 폭도 노브 기준 약 7mm로 동일).

## 1. 설계 목표 (4개 브랜드에서 가져온 것)
| 참고 | 특징 | 반영 |
|---|---|---|
| 파가니 유토피아 | 게이트식 7단 수동, 도그레그 1단, 링키지 노출 | 기둥 4개로 띄운 게이트, 메커니즘이 보이는 타워, **펌웨어에서 도그레그 배열 선택** |
| 페라리 (게이트 수동, 12Cilindri Manuale) | 금속 오픈 게이트, 좁은 중립 통로, 금속 클릭음 | **SUS304 3t 레이저 게이트**, 중립 통로 = 레버 + 1mm, 강철 레버가 강철 게이트에 닿는 소리 |
| 포르쉐 GT (GT4/GT3 쉬프터) | 짧은 스로우, 유격 없음, 좌우 스프링 복귀 | 축 볼트로 조인 625ZZ 짐벌(유격 0), 레버 길이 조절, **예압 걸린 좌우 센터링 스프링** |
| 부가티 투르비용 | 깎아낸 알루미늄, 시계 같은 노출 메커니즘 | 보이는 캠/롤러, 둥근 금속 노브, 널링된 모드 노브 |

## 2. 메커니즘
- **짐벌**: 앞뒤(θ) = 크래들이 타워의 625ZZ 2개 위에서 회전. 좌우(φ) = 허브가 크래들 안 625ZZ 2개 위에서 회전. 두 축이 한 점에서 만남.
- **앞뒤 손맛 = 롤러 캠 디텐트**: 크래들에 고정된 캠 + 스윙암(625ZZ 롤러 2개) + 금형 스프링.
  - 목표 노브 힘 곡선에서 **가상일(T·dθ = dU)로 캠 형상을 역산** (`source/cam.py`).
  - H 트랙: 중립 디텐트 약 7N → 싱크로 고개 **약 20N @5°** → 고개를 넘으면 **빨려 들어감**(−8~−10N) → 12° 금속 스톱.
  - 시퀀셜 트랙: 중앙 디텐트 → 점점 세지는 스프링 → **클릭 고개 약 20N @7.2°** → 벽 → 항상 중앙 복귀.
  - 시뮬레이션과 목표 오차 평균 약 0.6N (`images/feel_curves.png`).
  - 한계: 롤러 반경보다 경로 곡률 반경이 커야 해서 고개 폭이 약 3°(노브 기준 7mm) 필요.
- **좌우 손맛 = 2단 스프링**: 3-4 게이트에 기본 위치 (예압 약 5N). 1-2 / 5-6 약 10N. 7·R은 2단 스프링(S2)이 추가로 걸려 진입 문턱 약 20N, 끝까지 약 38N (사실상 후진 잠금). S2 나사로 조절.
- **모드 전환**: 앞쪽 노브를 180° 돌리면 → (1) 크랭크가 팔로워 캐리지를 Y로 18mm 이동 (H 트랙 ↔ SEQ 트랙), (2) 램프가 포크를 올려 꼬리 끝을 물어서 좌우 잠금. 양 끝이 크랭크 사점이라 저절로 고정됨. 중립에서만 전환.
- **센싱**: AS5600 ×2 (12비트, 비접촉). 펌웨어가 θ/φ → 게이트/기어 판정 (히스테리시스, 기어 중 게이트 고정).

## 4. 검증한 것
- CAD 간섭 검사 14개 자세 (중립, 모든 기어, 각 게이트, SEQ ±12°) + 모드 전환 이동 중 3개 지점: **간섭 없음** (기준 1mm³) — `source/check.py`
- 캠 시뮬레이션: 노브 힘 목표 대비 평균 오차 약 0.6N, 최대 스프링 힘 약 270N (금형 스프링 압축률 약 27%)
- 펌웨어: 기어 판정 로직 단위 테스트 (양쪽 배열, 히스테리시스, 기어 중 게이트 고정, SEQ 엣지) **전부 통과**, 스케치 문법 검사 통과
- **안 한 것**: 실물 출력/조립, 실제 공차, 보드용 컴파일 (이 환경에서 아두이노 툴체인 설치가 막혀 있었음)

## 5. 출력 가이드
- 재질: PETG 또는 ASA (Voron이면 ASA 추천). 캠(`cam_HS`)과 `hub`는 **채움 100%**.
- 하중 부품 (cradle, tower, arm, carriage): 6벽, 50% 자이로이드. 나머지 4벽 30%.
- STL은 출력 방향으로 돌려둠. 크래들은 박스 아래에 서포트 필요.
- 625 베어링 포켓 Ø16.1mm — 먼저 공차 테스트 한 장 출력 추천.

## 6. 조립 순서 (요약)
1. 인서트 압입: hub (M4 ×2), cradle (−Y 벽 M3 ×2, S2 끝 M6), carriage 브래킷 (M6), 타워 (+Y 스톱 M4 ×2, AS5600 브래킷 M3), 베이스 (M4 ×4)
2. 허브 + 레버 + 꼬리 (M6×55, 너트는 옆 슬롯) → 좌우 축 M5×45 + 625 ×2로 크래들에
3. 좌우 플런저/스프링: S1 왼쪽(자유장 24), S1 오른쪽(30), S2 + 컵 + M6 무두볼트
4. 캠을 크래들 −Y면에 M3 ×2로 고정
5. 타워를 베이스에 → 크래들 (앞뒤 축: −Y M5×50, +Y M5×20)
6. 캐리지 + 암 (M5×30 피벗) + 625 롤러 ×2 (M5×25) + 금형 스프링 + M6 예압 볼트 → 포크, 가이드, 크랭크 브래킷, 모드 크랭크 + 노브 (M5×40 축)
7. 기둥 (M5 전산볼트) + 게이트 → 노브
8. 배선 → 캘리브레이션 (중립 → 1단) → 튜닝

## 7. 튜닝
| 대상 | 조절 | 효과 |
|---|---|---|
| 앞뒤 전체 무게 | 캐리지 브래킷 위 M6 예압 볼트 | 곡선 전체 크기 |
| 7·R 잠금 무게 | 크래들 +Y 끝 M6 무두볼트 | 2단 스프링 예압 |
| 기어 들어가는 느낌 | +Y 타워 M4 스톱 나사 ×2 | 쇠 그대로 = 단단한 금속감 / TPU 캡 = 부드럽게 |
| 스로우 | 허브 안 레버 높이 | 짧게 = 짧고 무겁게 |
| 소리 | 게이트 재질 | SUS = 페라리식 클릭, 출력 = 조용 |
| 손맛 성격 | `cam.py`의 H_PROFILE_N (노브 힘 N 단위) | 원하는 곡선으로 캠 재생성 |

## 8. 알려진 리스크 / 다음 버전
- 출력 캠 마모 (PETG/ASA 접촉 응력 약 45MPa 추정, v0.1보다 약간 높음) → 닳으면 v0.3에서 금속 캠 (DXF 있음)
- 모드 전환 힘: 캐리지 약 85N 추정 → 크랭크 반경 9mm, 노브 레버 20mm로 손에는 약 40N. 무거우면 캐리지 바닥에 PTFE 테이프

- 금형 스프링 Ø12×25 중하중 k 값이 제조사마다 달라서 예압 볼트로 맞추기
