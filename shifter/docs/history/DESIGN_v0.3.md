# LSK H/SEQ 쉬프터 v0.3 (초소형, 알루미늄 판재 + 출력물) — 설계 문서

7단+R H패턴(표준/도그레그) ↔ 시퀀셜, 부품 예산 15만원 (예상 약 11.4만원, 알루미늄 가공 포함).

## 0. 크기 변화
| | v0.1 | v0.2 | **v0.3** |
|---|---|---|---|
| 가로×세로×높이 | 220×183×349 | 150×132×252 | **134×116×198mm** |
| 피벗→노브 / 피벗→게이트 | 190 / 118 | 140 / 75 | **110 / 55** |
| 레버 | SUS Ø12 | SUS Ø10 | **Ø8 리니어 샤프트** |
| 캠 | 출력, 반경 95 | 출력, 반경 62 | **Al 7075 판, 반경 45** |
| 구조 | 출력 타워 + 기둥 | 출력 타워 + 기둥 | **Al 6t 타워가 게이트까지 직접 지지** |
| 앞뒤 스로우 (노브) | ±40 | ±29 | **±27mm (14°)** |
- 몸체(베이스~게이트)는 약 125mm, 나머지는 레버와 노브.
- +Y 쪽 50mm 지점까지 나온 건 크래들 끝의 S2 예압 나사 (베이스 밖으로 10mm).

## 1. 왜 더 작아질 수 있었나
- **금속 캠**: 출력 캠은 접촉 응력 때문에 캠 반경을 못 줄였음. Al 7075(항복 약 500MPa)로 바꾸니 반경 45mm에서 접촉 응력 약 300MPa로 여유 있음.
- **짧은 레버**: 레버가 짧으면 같은 노브 힘에 필요한 토크가 줄어 → 스프링·캠이 같이 작아짐.
- **판재 구조**: 6mm 알루미늄 타워가 베어링 하우징 + 게이트 지지대 역할을 같이 함 (기둥 4개 삭제).

## 2. 손맛 (v0.1과 같은 목표 곡선)
- H: 중립 디텐트 약 7N → 싱크로 고개 **약 20N @6°** → 넘으면 빨려 들어감 (−8~−10N) → 14° 금속 스톱.
- 시퀀셜: 중앙 디텐트 → 클릭 고개 약 20N @8.4° → 끝 벽 → 항상 중앙 복귀.
- 고개 폭은 노브 기준 약 6.5mm (v0.1 7.3mm와 거의 같음). 시뮬레이션 오차 평균 약 0.7N.
- 좌우: 3-4 기본 위치 (예압 약 5N), 1-2/5-6 약 10N, 7·R 진입 문턱 약 20N, 끝까지 약 39N.

## 3. 4개 브랜드 반영
- **파가니**: 게이트 아래 메커니즘이 타워 창으로 보임, 도그레그 배열 (펌웨어 선택).
- **페라리**: 금속 오픈 게이트 (SUS 3t 추천), 좁은 중립 통로.
- **포르쉐**: 유격 없는 짐벌, 짧은 스로우, 좌우 스프링 복귀.
- **부가티**: 알루미늄 판재 + 금속 캠이 그대로 보이는 구조, 널링된 모드 노브.

## 4. 재료 구분
**알루미늄/금속 가공 (DXF_알루미늄판 폴더, 1:1 mm)**
| 부품 | 재질 | 수량 | 추가 작업 |
|---|---|---|---|
| base | Al 5t | 1 | 없음 |
| tower_negY / tower_posY | Al 6t | 각 1 | Ø16 구멍 F625 압입 공차 (리머 또는 CNC), 윗면 M3 탭 2곳씩 |
| gate | Al 3t 또는 SUS 3t | 1 | 모서리 바리 제거 |
| cam_H / cam_SEQ | **Al 7075-T6** 5t (또는 SUS304) | 각 2 (2장 겹침) | 정렬 구멍 M3로 맞춰 조립 |

**출력물 (STL_출력물 폴더)**
| 부품 | 재질 | 설정 |
|---|---|---|
| cradle, hub, carriage, arm | **ABS 또는 PETG** | 6벽 / 60% (hub 100%), 크래들은 서포트 |
| plunger ×3, cup, fork, crank, cam_spacer | ABS/PETG | 100% |
| knob, mode_knob, 클립 ×4, 레일, 가이드, 스톱 블록 | 아무거나 (PLA 가능) | 4벽 / 30% |
- **PLA는 스프링 하중 받는 부품에 쓰지 마세요** (시간 지나면 크리프로 손맛이 변함).
- Voron이면 ABS 추천 (강성·내열).

## 5. 검증
- CAD 간섭 검사 22개 자세 (모든 기어, 각 게이트 중간 위치, 시퀀셜 ±14°) + 모드 전환 이동 중 3지점: **간섭 없음**
- 캠 시뮬레이션 OK, 경로 곡률 반경 ≥ 롤러 반경 조건 만족
- 펌웨어 판정 로직 테스트 전부 통과, 스케치 문법 검사 통과
- **안 한 것**: 실물 조립, 보드 컴파일 (아두이노 IDE에서 확인 필요)

## 6. 조립 순서
1. 판재: 타워 Ø16 구멍에 F625 압입 (플랜지 바깥쪽), 윗면 M3 탭
2. 인서트: hub (M4 ×2), cradle (−Y면 M3 ×2, S2 끝 M5), carriage 브래킷 (M6), 스톱 블록 (M4 ×2), 클립 (M4 ×4)
3. 허브 + 레버(Ø8) + 꼬리(M5×45, 머리 아래, 너트는 옆 슬롯) → 좌우 축 M5×40 + 625 ×2로 크래들에
4. 좌우 플런저/스프링 (S1 좌 24, S1 우 30, S2 32 + 컵 + M5 무두)
5. 캠 스택: H 판 ×2 + 출력 스페이서 + SEQ 판 ×2 → M3×20 ×2로 크래들 −Y면, 정렬 구멍 M3로 맞춤
6. 타워 + 클립을 베이스에 → 크래들 (−Y M5×45, +Y M5×16)
7. 캐리지(레일·텅) + 암(M5×30) + 롤러 625 ×2(M5×25) + 금형 스프링 + M6 예압 → 포크·가이드·크랭크 브래킷·크랭크·모드 노브(M5×35)
8. 게이트를 타워 윗면에 M3 ×4 → 노브 → 배선 → 캘리브레이션 (중립 → 1단) → 튜닝

## 7. 튜닝
| 대상 | 조절 | 효과 |
|---|---|---|
| 앞뒤 무게 | 캐리지 브래킷 위 M6 무두볼트 | 곡선 전체 크기 |
| 7·R 잠금 | 크래들 +Y 끝 M5 무두볼트 | 2단 스프링 예압 |
| 기어 들어가는 느낌 | +Y 타워 바깥 스톱 블록의 M4 나사 | 쇠 = 단단, TPU 캡 = 부드럽게 |
| 소리 | 게이트 재질 | SUS = 클릭음, Al = 약간 둔함 |

## 8. 리스크
- 캠 7075 대신 6061을 쓰면 접촉 응력이 항복 근처 → 눌림 자국 생길 수 있음
- 레버 Ø8은 40N에서 노브 위치 약 0.4mm 휨 (보통 쓰는 20N이면 0.2mm) — 거슬리면 Ø10으로 바꾸고 허브·게이트 수정
- 타워 다리가 얇음(10~12mm) → 클립으로 단단히 고정, 필요하면 안쪽에 출력 보강대
- 모드 전환 노브는 손에 약 40N 추정 — 무거우면 캐리지 바닥 PTFE 테이프
- AS5600 보드 크기가 판매처마다 달라서 센서 브래킷은 실물 보고 출력
