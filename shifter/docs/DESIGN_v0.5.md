# LSK H/SEQ 쉬프터 v0.5 — 곡면 외장 / 설계 문서

> 제작: **Sunggwan**

v0.4 메커니즘(모듈 9개, CNC 6061, RP2040 + MT6701)은 그대로 두고 **겉모양만 곡면 셸로 다시 디자인**한 버전.
크기 133 × 127 × 199mm (모드 노브 포함 X 140), 부품 예상가 약 11만원.

## 1. 디자인 방향 (다른 제품·DIY에서 참고한 것)
- 시판 쉬프터 상당수가 사각 박스형 (예: Moza HGP는 리뷰에서 "직사각형 블랙 박스"로 묘사됨) → 박스에서 벗어나는 게 차별점.
- 고급 빌릿 쉬프터들의 공통 마감: 블랙 아노다이징 + 밝게 깎인 모서리, 볼엔드밀 홈 → 베이스·게이트 모따기로 반영.
- 레퍼런스 4개 브랜드:
  - **파가니**: 게이트가 셸 위에 뚜껑처럼 떠 보이는 구성
  - **페라리**: 금속 오픈 게이트와 각인된 기어 번호
  - **포르쉐**: 손바닥에 감기는 물방울형 노브, 짧은 스로우
  - **부가티**: 측면 창으로 캠·롤러(금속)가 보이는 '무브먼트' 연출, 생알루미늄 + 다크 그레이 투톤

## 2. 외형 구성
| 부품 | 형상 | 제작 |
|---|---|---|
| **M10 외장 셸** | 아래는 수직, 위로 갈수록 좁아지고 뒤쪽이 크게 기울어진 곡면 (단면 26개를 부드럽게 이은 로프트, 두께 2.6mm) | **ABS 출력 한 덩어리** (뒤집어서, 윗면이 베드), 사포 → 프라이머 → 무광 도장. 또는 6061 블록 3D 가공 |
| 게이트 (M7) | 셸 윗면과 같은 외곽의 76×98 뚜껑 — 셸과 한 면처럼 이어짐, 기어 번호 각인 | 6061 3t CNC |
| 노브 (M8) | 물방울형 회전체 (목 Ø17 → 배 Ø35 → 평평한 윗면), 윗면 H패턴 각인 | 출력 또는 CNC |
| 베이스 (M1) | 셸보다 3mm 큰 라운드 판, 앞쪽에 모드 노브용 반원 홈 | 6061 8t CNC |
| 창 | −Y: 타원 60×30 (캠·롤러) / +Y: 타원 42×20 (오렌지 카트리지 + 7·R 예압 나사 접근) | 셸에 포함 |
- 셸 고정: 바닥 보스 4개 (M3 인서트), 베이스 아래에서 볼트 → 밖에서 볼트가 안 보임.
- 내부 타워 외곽을 셸 안쪽에 맞게 조금 줄임 (윗면 X −36..32).

## 3. 색 구성 (추천)
- 셸: 다크 그레이 무광 / 게이트·노브·모드 노브: 생알루미늄 (비드 블라스트)
- 베이스: 블랙 아노다이징 + 모따기 면만 밝게
- 창 안: 오렌지 카트리지·잠금 암 (포인트 색)

## 4. 검증
- 셸 포함 **모든 부품 쌍 × 41개 자세** (H 모든 기어·중간 위치 ±3°/±7°/±11°, 시퀀셜 ±7.8°) → 간섭 0
- 손맛·펌웨어·배선은 v0.4와 동일 (`images/feel_curves.png`, `images/wiring.png`)

## 5. 셸 출력 팁 (Voron, ABS)
- 윗면(게이트 쪽)을 베드에 → 서포트는 바닥 보스·창 위쪽만
- 벽 4겹, 채움 20%, 0.2mm. 곡면 계단 자국은 0.12mm 가변 레이어 높이를 쓰면 줄어듦
- 마감: 240 → 400방 사포, 필러 프라이머, 무광 우레탄

## 6. 나머지
가공 목록·조립·튜닝·리스크는 v0.4 문서와 같음 (모듈 M1~M9). M10 셸은 마지막에 위에서 씌우고, 게이트를 덮은 다음 노브를 끼움.
