**v0.6 → v0.7: 전체를 좌우(Y) 반전**해서 운전석(+X, 모드 노브 면)에서 표준 7+R이 되게 했어요. 모든 부품이 v0.6의 거울상이에요.
- 맞바뀐 짝: M2-01/02 타워, M10-01(이제 −Y 렌치 구멍) / M10-02(이제 +Y 창), M4-02/03 플런저.
- 틈 보완: M4-01 카트리지(바닥 턱·끝 바닥 1.3 올림·카운터보어 1.5 깊게), M3-03 꼬리 캡(윗모서리 C1.8), M6-01 SEQ 잠금 암(탭 아랫면 R10.9 원호·옆면 릴리프).
- M7-01 게이트: 각인 배치가 바뀌어서 운전석에서 1·3·5·7이 먼 쪽에 오고, 1-2 칸이 왼쪽이에요.
- **v0.6 파일로 가공·출력하면 안 돼요.**
