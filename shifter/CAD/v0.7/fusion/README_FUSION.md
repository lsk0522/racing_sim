## 0. 너(Fusion 창의 Claude)에게 부탁하는 것
DIY 심레이싱 기어 쉬프터 **LSK H/SEQ Shifter v0.7**을 Fusion에서 이어서 설계하고 검토해 줘.
설계 원본은 GitHub 레포의 파이썬 build123d 코드이고, 아래 STEP 파일로 Fusion에 그대로 불러올 수 있어.
무엇을 할지는 사용자가 정해. 시작하면 먼저 파일이 잘 열렸는지 확인하고, 사용자에게 오늘 할 일을 물어봐 줘.

할 수 있는 일 예시 (사용자가 고르면 진행):
- 책상 위 배치, 손 닿는 위치, 외관 확인, 렌더
- 조인트·움직임 확인 (앞뒤 ±14°, 좌우 게이트 4칸, 시퀀셜 ±8°)
- 부품 형상 수정 (아래 "바꾸면 안 되는 것" 지키기)
- CNC 가공 경로(Manufacture/CAM) 준비 — 6061 판·블록 부품
- 출력 부품의 출력 방향·서포트 검토

v0.6 → v0.7 (11-27): v0.6 Fusion 검토에서 **운전석에서 보면 H 패턴이 180° 돌아가 있는 문제**를 찾았어.
그래서 **기구 전체를 좌우(Y) 반전**해서 운전석에서 표준 7+R이 되게 했어.
틈이 부족한 곳 4곳도 같이 고쳤어(카트리지·꼬리 캡·SEQ 잠금 암). 자세한 것은 `shifter/docs/DESIGN_v0.7.md`에 있어.

### Fusion으로 열 때
1. **환경설정 → 일반 → 기본 모델링 방향을 "Z 위쪽"**으로 바꾸고 불러와. 기본값인 Y 위쪽이면 쉬프터가 누워서 보여.
2. 단위는 **mm**야. 조립 STEP을 열면 부품마다 컴포넌트로 들어와.
3. 이미 조립된 상태(중립, 3-4 게이트 가운데)라서 원점 고정(Ground)만 하면 돼.

## 2. 좌표계 (v0.7 최종 좌표 — STEP·도면 공통)
- 원점은 **짐벌 피벗 중심**(레버가 도는 점)이야. 단위는 mm, 각도는 °.
- **+X = 운전석 쪽**(모드 노브가 있는 면, 책상 앞 모서리), −X = 먼 쪽(USB-C).
- **−Y = 운전자 왼쪽**: 1-2 칸, S2 예압 렌치 구멍, 모드 노브 축, 배선 중공 핀이 이쪽이야.
- **+Y = 운전자 오른쪽**: 7-R 칸, 캠·롤러, 피치 센서 캡, 작은 창이 이쪽이야.
- **+Z = 위**. 게이트 윗면 z 57, 베이스 아래면 z −74, 바닥 커버 아래면 z −76, 책상 윗면 z −83 (실리콘 1mm 포함).
- 몸체 외곽은 X −84 ~ 46, **Y −51 ~ 67.5** (130 × 118.5)이고, 전체 높이는 202야(노브 끝 포함).
- 소스: `shifter/src/cad.py`(최종)는 `cad_model.py`(반전 전 모델 좌표)를 Y로 뒤집은 것이야. `cad_model.py`와 PARAMS.csv의 Y 상수는 부호를 바꿔서 읽어.

## 5. 규칙 (꼭 지키기)
1. **원본은 레포의 파이썬 코드**(`shifter/src/cad_model.py` + `cad.py`)야. Fusion은 검토, 시도, 렌더, CAM용이야.
   - Fusion에서 형상이나 치수를 바꾸면 프로젝트 문서 **`claude/FUSION_CHANGES.md`**에 `품번 · 무엇을 · 전 값 → 새 값 · 이유 · 날짜`로 적어. 좌표는 **v0.7 최종 좌표**로 적어.
   - 그러면 레포 작업 대화가 cad_model.py에 반영하고(Y는 부호 바꿔서) → 간섭 검사 `check.py` → `export.py` → `fusion_pack.py` → 도면(`make_drawings.py`) → PR 순서로 올려.
   - 사용자가 "이제부터 Fusion이 원본"이라고 정하면, 그 결정을 `claude/RACING_SIM_DESIGN.md`에 적고 따라.
2. **바꾸면 안 되는 것**(손맛·센서가 이 값에 맞춰져 있어): 피벗 위치, 피벗→노브 110·게이트 55, 캠 윤곽, 롤러·스프링 위치, 게이트 슬롯 간격 15mm, 베이스 M6 40mm 패턴, 센서 자석 위치. 바꿔야 하면 먼저 사용자에게 이유를 설명하고 허락받아.
3. 부품끼리 **겹침 0**을 유지해(모든 기어 위치에서). 갭은 출력 1.2 / 금속 1.0이야. 1 mm³보다 작은 겹침도 놓치지 마(`check.py`가 "작은 겹침 경고"로 보여 줘).
4. 소재: 금속은 **6061만** 쓰고 **아노다이징은 안 해**(무처리·비드 블라스트, 챔퍼만 다시 깎아 가공면 노출). 출력은 ABS/PETG이고, 스프링 힘 받는 부품에 PLA는 금지야.
5. 새 부품은 품번 `M모듈-번호`, 이름 `품번_부품`으로 붙여(예: `M12-07_pad_clip`).
6. 2D 스케치는 직선·원호·스플라인으로 그려(다각형 근사 금지). 그래야 STEP과 도면이 매끄러워.
7. 도면은 레포 생성기가 만들어(A4 가로 기본, 큰 판재는 A3 가로, 흑백, ISO 2768-mK · ISO 286 · ISO 1101 · ISO 13715 · ISO 21920, 3각법, 실무 표제란 양식). Fusion 도면이 필요하면 같은 규칙으로 해. **v0.6 도면으로 가공하면 안 돼**(v0.7은 전부 거울상).
8. 예산: 부품 15만원(배송비·공구 제외). 지금 본체 142,600원 + 클램프 15,000원이고, 6061 판재값은 평균가 추정(kg당 약 2만원)이야.

## 6. 지금 상태 · 남은 것 (2026-11-27)
- v0.7은 좌우 반전에 틈 보완 4건을 더한 버전이야. 간섭 0(41개 자세 + 책상 15/28/38mm)이고, 1° 간격 스윕 146 자세도 확인했어.
- 남은 작은 겹침 경고는 1건이야. SEQ 7.8°에서 잠금 암 ↔ 꼬리 캡이 닿는데, v0.6부터 있던 것이고 실제 시퀀셜 스톱이 약 7.6°라는 뜻이야.
- 확인 필요: 데스커 책상 밑, 앞 모서리에서 안쪽으로 **55mm 이상** 프레임·서랍이 없는지 (클램프 아래 턱이 들어갈 자리).
- 다음 순서: 손맛 프로토타입(M3 짐벌 + M5 디텐트 + 타워 1장 + 베이스) 가공 → 손맛 확인 → 캠 조정 → 전체 조립 → 펌웨어 실기 확인.
- 그다음 모듈: 핸들(퀵릴리즈 사용) → 페달. 나중에 데스크톱 GUI 설정 앱.
