# CAD 산출물 (버전별) — 제작: Sunggwan

리비전마다 폴더 하나. 이전 버전 폴더는 지우지 않는다. 새 버전은 `src/export.py`의 `VERSION`을 올려서 생성.

```
CAD/vX.Y/
  mach/sheet/   판재에서 가공하는 부품   STEP + 1:1 외곽 DXF (CAM 바로 사용)
  mach/block/   블록·봉에서 가공하는 부품 STEP
  print/        3D 출력 부품           STL (출력 방향으로 돌려 바닥 Z=0) + STEP
  buy/          구매품                 참고 STEP + BOM.csv
  assembly/     전체 조립 STEP, 서브 조립, parts_table.csv (품번·소재·크기), geometry.json
```
가공 도면(치수·공차·기하공차·후처리)은 [`../docs/dxf/`](../docs/dxf/).

v0.5부터 STEP은 **매끄러운 B-rep**: 2D 형상의 선분 묶음을 `src/smooth2d.py`가 직선·원호·스플라인으로 바꿔서 돌출한다
(예: 타워 면 1544 → 149개, 원은 실제 원통면). CAM 툴패스와 도면 모두 이 STEP을 기준으로 한다.

| 버전 | 상태 | 비고 |
|---|---|---|
| [v0.7](v0.7/) | **현재** | v0.6 전체 좌우 반전 → 운전석(+X)에서 표준 7+R, 틈 보완 (카트리지·꼬리 캡·SEQ 잠금 암), 도면 18장 |
| [v0.6](v0.6/) | 이전 | 면 분할 블록 외장 (M10 패널·커버, M11 부트), 도면 15장 |
| [v0.5](v0.5/) | 이전 | 곡면 셸, 품번 체계(M1-01…), 도면 11장 |
| [v0.4](v0.4/) | 이전 | 모듈 9개, 6061 전용 |
| [v0.3](v0.3/) | 이전 | 판재 타워·게이트 (출력 위주) — 옛 패키지를 같은 폴더 구조로 재분류 |
| [v0.2](v0.2/) | 이전 | 출력 위주, 판재는 DXF만 |
| [v0.1](v0.1/) | 이전 | 첫 설계 |

v0.1~v0.4는 당시 패키지를 확장자 기준으로 재분류한 것 (DXF→`mach/sheet`, STL→`print`, 나머지 STEP→`assembly`). 그때는 대부분 출력 부품이었다.
