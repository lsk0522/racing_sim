## 0. 너(Fusion 창의 Claude)에게 부탁하는 것
DIY 심레이싱 기어 쉬프터 **LSK H/SEQ Shifter v0.6**을 Fusion에서 이어서 설계·검토한다.
지금까지의 설계는 GitHub 레포(파이썬 build123d 코드)로 만들어져 있고, 아래 STEP 파일로 Fusion에 그대로 불러올 수 있다.
무엇을 할지는 사용자가 정한다. 시작하면 먼저 파일이 잘 열렸는지 확인하고, 사용자에게 오늘 할 일을 물어본다.

할 수 있는 일 예시 (사용자가 고르면 진행):
- 책상 위 배치·손 닿는 위치·외관 확인, 렌더
- 조인트·움직임 확인 (앞뒤 ±14°, 좌우 게이트 4칸, 시퀀셜 ±8°)
- 부품 형상 수정 (아래 "바꾸면 안 되는 것" 지키기)
- CNC 가공 경로(Manufacture/CAM) 준비 — 6061 판·블록 부품
- 출력 부품 출력 방향·서포트 검토

### Fusion으로 열 때
1. **환경설정 → 일반 → 기본 모델링 방향 = "Z 위쪽"**으로 바꾸고 불러오기 (기본값 Y 위쪽이면 쉬프터가 누워서 보임).
2. 단위 **mm**. 조립 STEP을 열면 부품마다 컴포넌트로 들어온다.
3. 위치는 이미 조립 상태(중립, 3-4 게이트 가운데)라 원점 고정(Ground)만 하면 된다.

## 2. 좌표계 (모든 파일 공통)
- 원점 = **짐벌 피벗 중심** (레버가 도는 점). 단위 mm, 각도 °.
- **+X = 앞 = 운전석 쪽** (모드 노브가 있는 면, 책상 앞 모서리 쪽), −X = 뒤 (USB-C).
- **+Y = 스프링 카트리지 쪽 타워**, −Y = 센서 캡·작은 창 쪽.
- **+Z = 위**. 게이트 윗면 z 57, 베이스 아래면 z −74, 바닥 커버 아래면 z −76, 책상 윗면 z −83 (실리콘 1mm 포함).
- 몸체 외곽 X −84 ~ 46, Y −67.5 ~ 51 (130 × 118.5), 전체 높이 202 (노브 끝 포함).

## 3. 주요 값
| 항목 | 값 |
|---|---|
| 피벗 → 노브 잡는 중심 / 피벗 → 게이트 | 110 / 55 |
| 앞뒤 스로우 (θ) | ±14° (금속 스톱), 시퀀셜 ±8° |
| 좌우 게이트 (φ) | 1-2 +15.26° · 3-4 0° · 5-6 −15.26° · 7-R −28.61° |

| 디텐트 | 625ZZ 롤러 3개 + 6061 캠 (반경 45) + 금형 스프링 Ø12×25 |
| 베이스 아래 장착 | **M6 탭 4개, 40mm 간격**: (−60,−40) (−20,−40) (−20,20) (20,20) |
| 섀도우 갭 | 출력 부품 경계 1.2 / 금속끼리 1.0 |
| 책상 클램프 (M12) | 데스커 상판 28mm 기준, 15~38mm 사용, 벌림 48, 책상 밑으로 47 들어감, M10×50 + 별 손잡이 |

## 5. 규칙 (꼭 지키기)
1. **원본은 레포의 파이썬 코드** (`shifter/src/cad.py`). Fusion은 검토·시도·렌더·CAM용.
   Fusion에서 형상이나 치수를 바꾸면, 바꾼 내용을 프로젝트 문서 **`claude/FUSION_CHANGES.md`**에 적는다:
   `품번 · 무엇을 · 전 값 → 새 값 · 이유 · 날짜`. 그러면 레포 작업 대화가 cad.py에 반영 → 간섭 검사(`check.py`) → `export.py` → 도면(`make_drawings.py`) → PR 순서로 올린다.
   (사용자가 "이제부터 Fusion이 원본"이라고 정하면 그 결정을 `claude/RACING_SIM_DESIGN.md`에 적고 따른다.)
2. **바꾸면 안 되는 것** (손맛·센서가 이 값에 맞춰져 있음): 피벗 위치, 피벗→노브 110·게이트 55, 캠 윤곽, 롤러·스프링 위치, 게이트 슬롯 간격 15mm, 베이스 M6 40mm 패턴, 센서 자석 위치. 바꿔야 하면 먼저 사용자에게 이유를 설명하고 허락받기.
3. 부품끼리 **겹침 0** 유지 (모든 기어 위치에서). 갭은 출력 1.2 / 금속 1.0.
4. 소재: 금속은 **6061만**, **아노다이징 안 함** (무처리 · 비드 블라스트, 챔퍼만 다시 깎아 가공면 노출). 출력은 ABS/PETG — 스프링 힘 받는 부품에 PLA 금지.
5. 새 부품은 품번 `M모듈-번호`, 이름 `품번_부품` (예: `M12-07_pad_clip`).
6. 2D 스케치는 직선·원호·스플라인으로 (다각형 근사 금지) — STEP·도면이 매끄러워야 함.
7. 도면은 레포 생성기가 만든다 (A4 가로 기본, 큰 판재 A3 가로, 흑백, ISO 2768-mK · ISO 286 · ISO 1101 · ISO 13715 · ISO 21920, 3각법, 실무 표제란 양식). Fusion 도면이 필요하면 같은 규칙으로.
8. 예산: 부품 15만원 (배송비·공구 제외). 지금 본체 142,600원 + 클램프 15,000원. 6061 판재값은 평균가 추정 (kg당 약 2만원).
