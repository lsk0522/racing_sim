## 4. 사양표 (쉬프터 v0.5)
| 항목 | 값 |
|---|---|
| 크기 | 133 × 127 × 199mm |
| 피벗→노브 / 피벗→게이트 | 110 / 55mm |
| 앞뒤 스로우 | ±14° (노브 ±27mm), 시퀀셜 ±8° |
| 좌우 게이트 | 15mm 간격 (1-2 +15.3°, 3-4 0°, 5-6 −15.3°, 7-R −28.6°) |
| 디텐트 | 롤러(625×3) + 6061 캠 (반경 45), 금형 스프링 Ø12×25, 싱크로 고개 약 20N |
| 좌우 스프링 | 외경8 선경1.0 자유장 24/30/27 (S1좌/S1우/S2) |
| 베어링 | 625ZZ ×5, F625ZZ ×2 |
| 레버 | Ø8 경화 리니어 샤프트 |
| 센서 / MCU | MT6701 ×2 (I2C0/I2C1) / RP2040-Zero |
